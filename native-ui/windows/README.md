# UU Link Windows x64 预览

这是一款 Windows 10/11 x64 的 TCP/UDP 端口转发控制端。远端继续运行支持相应协议的 UU Link 服务。当前没有 ARM64 原生包，也不包含 Windows 被控端。

- 从安装包安装后在开始菜单打开 **UU Link**。安装不要求管理员权限，缺少 WebView2 时会联网安装 [Microsoft Evergreen Runtime](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。
- 便携版请完整解压后打开 **UU Link.exe**，并保留同目录的 **uulink-engine.exe**。若没有 WebView2，请先安装 Microsoft Runtime。
- 应用默认只允许本机访问映射。为单条映射开启“允许局域网访问”后，还需要 Windows 防火墙允许所需端口；建议仅允许信任的专用网络。
- UU 连接只使用 Windows 报告为物理硬件、具有 IPv4 默认路由的以太网或 Wi-Fi；无合适接口时连接会失败，不回退到普通路由或代理。第三方驱动和 Windows 网络过滤器仍可能阻断流量。
- 默认关闭窗口后留在系统托盘并继续转发，点击托盘图标恢复窗口。托盘菜单的“退出 UU Link（断开连接）”会停止转发并退出，设置中可关闭后台运行。登录时启动由当前 Windows 用户的登录项管理，可在应用设置关闭。卸载保留 `%LOCALAPPDATA%\UU Link` 中的本机账户和映射配置。
- 首个预览未签名。下载后可用 `Get-FileHash -Algorithm SHA256` 与发行页的摘要文件核对。

## 实机验收清单

### 2026-11-05 自绘安装向导

`fixed5` 安装程序使用与主程序共用的 Go/WebView2 窗口框架，自绘准备、进度、完成和错误重试页面。界面沿用浅深色主题、紫色主按钮、圆角卡片、应用图标与沉浸式顶部。安装位置可在页面内修改，完成后可选择打开 UU Link。

文件安装由内嵌的静默后台执行，界面轮询实际安装阶段。Windows 11 上已完成运行中更新拦截、退出旧版本后重试、覆盖安装、开始菜单入口创建和完成后启动软件的完整交互验证。根模块与 `uulink_setup` 构建均通过测试。后台开关及弹窗圆角修复也包含在此包中。

构建脚本先构建应用和静默后台，再使用 `uulink_setup` 构建标记生成独立安装程序。缺少 WebView2 时先运行内嵌的 Microsoft 引导程序。Windows 10、干净系统上的运行库引导、多显示器混合 DPI，以及带真实远端转发的长期后台运行仍待验收。

当前本地安装包为 `dist/UU-Link-0.3.5-windows-x64-fixed5-setup.exe`。它支持 `/S` 静默安装与 `/D=完整目录` 安装位置参数，卸载继续使用安装目录中的 `Uninstall.exe`。

### 2026-11-05 圆角与后台运行更新

`fixed4` 为内嵌 WebView 增加原生圆角裁切，并对弹窗遮罩同步设置圆角。添加映射弹窗已在 Windows 11 浅色模式实测，最大化窗口使用矩形内容区域。

Windows 版增加系统托盘，默认启用“关闭窗口后继续运行”，与 Mac 版默认行为一致。关闭窗口隐藏界面，连接引擎仍由同一应用进程管理。点击托盘图标或再次启动软件可恢复窗口。托盘菜单包含打开、连接、断开与明确退出，设置的“关于”页也提供“退出软件”。关闭后台开关后，关闭窗口会完整退出。系统注销或关闭及界面故障会走完整退出流程。

已实测关闭后保持同一进程和本地服务监听、再次启动恢复窗口、关闭后台开关后退出并清除会话文件及监听。回归测试覆盖旧设置迁移、默认开启、明确关闭的持久化与其他设置保存时的状态保留。Windows 10、Explorer 重启恢复、托盘菜单鼠标交互和带真实远端转发时的后台持续收发仍待验收。

本地安装包为 `dist/UU-Link-0.3.5-windows-x64-fixed4-setup.exe`，对应便携包与摘要也在 `dist`。

### 2026-11-05 图标与沉浸式窗口更新

`fixed2` 本地测试包移除了可见的系统标题栏，导航、应用图标和最小化、最大化、关闭按钮位于同一顶部区域。顶部空白区域由 WebView2 原生拖动区域处理，支持拖动、双击最大化及右键系统菜单。边缘保留与应用背景同色的 Windows 原生缩放区域，最大化后移除该区域。

`AppIcon.ico` 从现有 `gui_assets/icon.svg` 生成，包含 16、24、32、48、64、128、256 七种尺寸。打包直接使用此文件，避免 SVG 转换器生成黑色图标。Windows 回归测试检查每个尺寸的图像数据及紫色背景。

Windows 11 上已实测顶部拖动、双击最大化、最大化与还原按钮、最小化与恢复、右边缘缩放、关闭，以及浅色和深色显示。更新后的安装包覆盖安装返回 0。Windows 10、多显示器混合 DPI 和最大化按钮悬停贴靠菜单仍待实测。

安装包为 `dist/UU-Link-0.3.5-windows-x64-fixed2-setup.exe`，对应便携包与 SHA256 摘要也在 `dist`。可执行文件版本仍为 0.3.5，包名中的 fixed2 区分此次本地修复。

### 2026-11-05 Windows 验证记录

环境为 Windows 11 专业工作站版 Insider Preview x64，系统构建 29698，WebView2 156.0.4314.58。

发行版 `v0.3.5-windows.1` 的安装包与便携包 SHA256 均匹配发行摘要。原安装包静默安装返回 0，但主程序在进入 main 前因 WebView2 生成绑定中的 Go string 回调参数而 panic，无法启动。

本地修复绕过存在初始化错误的生成绑定，保留导航和弹窗限制，并修正导航 URL 的 COM 字符串输出指针。另修复 Windows 写入配置后的目录 Sync 错误，主程序和连接引擎同时调整。仓库遗漏的 `vendor/magpie.css` 已从 Magpie 固定提交恢复，来源记录在文件头，许可见第三方声明。

本地修复包为 `dist/UU-Link-0.3.5-windows-x64-fixed1-setup.exe` 和对应便携 ZIP，版本号仍为 0.3.5。这些是本地测试产物。

已通过以下检查。

- 原包全新静默安装、修复包覆盖安装、卸载和再次安装均返回 0。
- 安装文件、当前用户开始菜单快捷方式和卸载注册项正常生成。卸载后这三项清除，本地配置目录保留。
- 修复包安装后打开主界面与设置页，浅色和深色正常显示，重启后保留深色主题。
- 第二次启动退出码为 0，保持单个应用进程。点击窗口关闭后应用退出，17633 监听和 session.json 清除。
- 引擎 version、物理网卡 HTTPS、原生 UDP DNS 与 ICE 候选诊断通过。
- 根模块与引擎模块的 `go test ./...` 通过。新增 Windows 回归检查覆盖配置首次写入、覆盖写入和页面资源完整性。

尚待验收的项目包括 Windows 10、普通非管理员账户、缺少 WebView2 时的自动安装、交互式安装向导、SmartScreen、短信登录、真实远端 TCP/UDP 转发、局域网访问、断网重连、登录自启、防休眠与带转发引擎运行时的强制退出清理。`go vet` 仍报告窗口消息处理代码原有的两处 unsafe.Pointer 提示。

本轮在 Windows 上编译主程序和引擎。安装包沿用 NSIS 脚本，临时副本仅将输入文件路径分隔符调整为 Windows 格式，应用图标和清单从原发行程序提取后嵌入。

使用测试映射和一个支持相应协议的远端。不要让 Windows 与现有客户端同时连接同一个正在使用的 UU 隧道，以免影响已有连接。

1. 在 Windows x64 上安装和打开，检查标题栏、图标、窗口缩放，以及切换系统浅色与深色后的外观。关闭再打开，检查主题和映射设置是否保留。
2. 用首次登录的身份发送一次短信验证码，输入验证码后确认设备列表。记录失败的 HTTP 状态、错误码和界面提示；不要共享手机号、验证码或身份文件。
3. 新建两条映射，使用实际 TCP 和 UDP 服务验证数据收发。增删或停用其中一条，确认另一条仍能收发；再断开并恢复 Windows 网络，观察恢复情况。
4. 用第二台局域网设备测试一条映射：关闭“允许局域网访问”时无法连接，开启后在防火墙允许的情况下可以收发。在线设备可测 UU 隧道延迟，离线设备不应显示测量按钮。
5. 从便携目录执行下列只读诊断。开启和关闭系统代理或虚拟网卡分别检查，预期 UU 连接使用同一块可用物理网卡，且没有物理路由时报告错误。诊断不会读取账号或启用转发。

   ```powershell
   .\uulink-engine.exe version
   .\uulink-engine.exe network-check --udp --ice --timeout 35s
   ```

6. 开启防止自动休眠后运行 `powercfg /requests`，关闭软件后再检查请求是否释放。确认 Windows 登录项关闭、开启及再次登录后的行为。
7. 关闭软件，确认没有 `uulink-engine.exe` 残留、映射端口不再监听。对测试配置重复一次，结束 **UU Link.exe** 进程，检查 Job Object 也能清理子进程。最后卸载，确认开始菜单和安装文件清除。

## 构建

在 macOS 或 Linux 上准备 Go、NSIS、curl、zip 和 shasum，从仓库根目录执行：

```bash
./native-ui/windows/package.sh ./dist
```

这个命令从源码生成两种 Windows x64 分发包与 SHA256 文件。Windows 应用源代码由根模块的 `gui_*_windows.go`、`gui_assets/` 和独立的连接引擎模块 `experiments/udp-game-adaptive/` 组成。MS WebView2 Runtime 是桌面界面的外部运行依赖。

当前验证包括交叉构建及安装包内容检查。上述 Windows 实机行为需要单独验收。
